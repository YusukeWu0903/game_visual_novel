# 明日之星對話系統移植（2026-10-23）

採用使用者選擇的整套對話演出移植：首頁沿用慾之穹頂，遊戲內使用明日之星的固定 1280×720 舞台與對話版面。原版保存在 `/legacy.html`，原 `src/main.js`、CSV、JSON、霞與劍舞素材維持可比較版本。

## 本機使用

在 `web-visual-novel` 執行 `npm run dev`。首頁提供三段既有示範：

- Event0004：Sophia 分層組裝、Maru 待機眨眼、說話者聚焦、雙角色與退場。
- Event0003：三選一分支、回接、獎勵收據、BGM、音效與環境音。
- Event0005：彩色黑幕旁白、一般對話、CG、再次黑幕與場景恢復。

點擊對話框，打字中先補齊全文，再點前進。對話工具列提供紀錄、文字速度與隱藏介面。按 Escape 先關閉紀錄／恢復介面，再按可退出演出。逐節點自動保存，首頁「讀取進度」繼續最後一段未完成演出。只有一份繼續進度；新遊戲會替換它。舊版十槽存檔使用另一個 key，不與新存檔混用。

手機沿用來源規格：橫向、至少 640×360；直向提示旋轉裝置。舞台整體等比縮放，對話框不另行換行重排。

## 移植邊界與維護

- `public/stardom/runtime/`：36 個必要的原生 ES 模組與分層 renderer，開發與正式版直接使用同一份。無須啟動或連線 game_dual-realm。
- `vendor/stardom/source/`：對應 TypeScript 參考源碼，不是完整明日之星倉庫，也不是本專案的自動編譯輸入。後續直接修改執行 JS 時，同步更新相應 TS 參考。
- `public/assets/graphics/`：已採用角色、動態 manifest、圖層、眼部、景深及示範場景。依穩定 Graphic ID 載入；不是新增生圖。
- `public/stardom/snapshot.json`：來源快照的檔案大小與 SHA256。這是匯入基準，不表示下述本作修補仍與來源逐位元相同。
- `scripts/import-stardom-dialogue.mjs`：首次匯入工具，已有快照時拒絕覆寫。重新同步前先比較本地變動、保存回復候選，不能直接刪快照重跑。
- `public/stardom/app.js`：本作首頁與播放接合。
- `public/stardom/dialogue-save.js`：版本化、穩定節點 ID、已選分支、收據與完成狀態。
- `public/stardom/restore-route.js`：只重建已選路徑，不播放其他分支、不再次發獎。
- `vite.config.js`：首頁與舊版雙入口正式建置。

來源試播器依賴遊戲 controller；本作提供較小的儲存接頭，沒有引入整個養成遊戲。獎勵是流程與收據示範，尚未接本作的背包／屬性模型；不能宣稱有完整遊戲經濟。示範音訊不等於正式配樂。來源 Excel 編輯器與匯入管線未移入，本次使用已產出的資料模組，修改明日之星工作簿不會自動更新本作。
